# company_profile.md 양식

작업 폴더에 두는 회사별 기준 파일이다. 스킬은 시작할 때 이 파일을 먼저 읽고, 여기 적힌 내용을 기본값보다 우선한다. 첫 실행이 끝난 뒤 사용자가 동의하면 이번에 정해진 내용으로 이 파일을 만든다. 숫자 자료가 아니라 "정해 둔 기준"만 적는다.

```markdown
# 회사 기준 — <회사명>

- 작성일: YYYY-MM-DD / 작성 근거: <누가 정했는가>

## 사업 요약
<무엇을 누구에게 파는가, 매출이 무엇에 따라 움직이는가. 두세 문장>

## 보고 기준
- 표시 단위: 백만원
- 사업연도: 1월~12월
- 평소 쓰는 양식: <있으면 파일 이름과 따를 점>

## 계정 분류
| 원장 계정 | 모델 라인 | 손익 구분 | 비고 |
|---|---|---|---|

## 매출 추정 방식
| 매출 라인 | 방식 | 기준 자료 | 비고 |
|---|---|---|---|

## 비용 추정 방식
| 비용 라인 | 방식 | 기준 | 비고 |
|---|---|---|---|

## 승인된 가정
| 항목 | 값 | 정한 사람·날짜 |
|---|---|---|
| 최소 보유현금 | | |
| 한도대출 한도 | | |
| 임금 인상률 | | |
| 만기 도래 차입의 처리 | | |
| 세법상 중소기업 여부, 결산월 | | |
| 반복되는 세무조정 항목과 금액 | | |

## 시나리오 정의
- Up:
- Down:

## 자료를 받는 곳
| 자료 | 파일 이름 규칙 | 담당 |
|---|---|---|

## 주의할 점
<이 회사 자료의 특이 사항. 예: 손익이 누계로 나온다, 12월에 상여가 몰린다>
```
