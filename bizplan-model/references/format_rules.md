# 산출 Excel의 구성과 서식

엔진(`build_model.py`)이 이 기준대로 만든다. 이 문서는 사용자에게 모델을 설명할 때, 그리고 확장 시트를 붙일 때 읽는다. 투자·재원조달 → 운영 → 재무제표 순서로 읽는 표준 재무모델 구성을 따른다.

## 시트 구성

| 구역 | 탭 색 | 시트 | 내용 |
|---|---|---|---|
| 본표 | 주황 `#FF6600` | 목차 | 시트 목록과 바로가기, 모델 안내 |
| | | Sensitivity | 케이스 선택, 케이스별 스위치, 결과 저장값, 단추 2개 |
| | | 전제사항 | 사용자가 바꾸는 가정 |
| | | 민감도및결과 | 연도별 결과, 세 안 비교, 민감도, 검증 집계 |
| | | 금융조건 | 차입 약정 조건과 상환 예정 원금 |
| | | INDEX | 월 시계열, 실적·추정 구분, 지수 |
| | | 투자비 | 취득, 감가상각, 장부가 |
| | | 재원조달 | 약정별 잔액·상환·이자, 한도대출, 신규 조달 |
| | | 운영수입 | 매출 라인별 집계 |
| | | 운영비용 | 매출원가, 판매관리비 |
| | | IS, BS, CF | 재무제표 |
| | | BS명세 | 계정별 기초·증감·기말 |
| 가정·상세 | 연주황 `#FFB380` | 매출 라인별 상세, 인건비 | 동인별 계산 |
| 실적·원천 | 진회색 `#595959` | 실적_IS, 실적_BS, 실적_차입 등 | 정규화 자료 원본 |
| 검증·관리 | 회색 `#A6A6A6` | 검증, 기준값갱신, 스타일 가이드, 모델정보 | 대사, 매크로 대상 표, 서식 기준, 구조 정보 |

재무상태표 자료가 없으면 BS와 BS명세는 만들지 않는다.

## 화면 규칙

- A1 프로젝트명, A2 시트 제목. 1행은 구역 색 띠
- B~F열은 좁은 들여쓰기 열(항목 계층), G열 기준값·단위, H열 "Sum or Max", J열부터 월 시계열, 월 뒤에 연도 합계 열
- 머리글 3행(연도, 월, 실적/추정 구분), 틀 고정
- 글꼴은 두 가지만 쓴다. 글자는 `맑은 고딕`, 숫자·날짜 칸은 `Arial`, 본문 10pt. 차트는 한글 `맑은 고딕`, 영문·숫자 `Arial`, 9pt(제목 10.8pt)
- 숫자 `#,##0_-;[Red](#,##0);"-"_-`, 비율 `0.0%`, 배수 `0.00"x"`. 음수는 빨간 괄호
- `민감도및결과`는 위에서부터 지표 카드(값과 전년 대비 증감), 차트 4개(연도별 매출, 매출 브리지, 시나리오별 DSCR, 월별 매출·EBITDA·영업이익), 연도별 표, 세 안 비교, 검증 순서다

## 색상표

모델 안의 `스타일 가이드` 시트가 기준이다. 아래 색만 쓴다. 녹색·남색 계열과 줄무늬 채움은 쓰지 않는다. 검증(`verify_model.py`)은 이 밖의 색이나 글꼴이 있으면 경고로 위치를 알려 준다.

| 용도 | 색 | 글씨 |
|---|---|---|
| 본표·가정·검증 시트 1행 띠, 구역 제목 밑줄, 선택된 케이스, 단추, 강조 | 주황 `#FF6600` | 흰색 |
| 실적·원천 시트 1행 띠 | 진회색 `#595959` | 흰색 |
| 2행 제목 띠, 요약 표와 지표 카드 머리글 | 회색 `#C0C0C0` | 제목 띠는 흰 볼드, 머리글은 검정 볼드 |
| 입력(사용자가 바꾸는 값) | 노랑 `#FFFF00` | 파랑 `#0000FF` |
| 계산·링크 | 채움 없음 | 검정 |
| 경고(NO, 갱신 필요, 음수) | 채움 없음 | 빨강 `#FF0000` |
| 테두리 | 검정 얇은 실선 | |
| 탭 색 전용 | 연주황 `#FFB380`, 회색 `#A6A6A6` | 셀에는 쓰지 않음 |

## 차트 색

| 차트 | 색 |
|---|---|
| 주 계열(매출, 선택된 케이스) | `#FF6600` |
| 보조 계열 순서 | `#C0C0C0` → `#A6A6A6` → `#595959` → `#FFB380` |
| 매출 브리지 | 양 끝 `#C0C0C0`, 증가 `#FF6600`, 감소 `#FF0000` |
| 시나리오별 DSCR | 선택된 케이스 `#FF6600`, 나머지 `#C0C0C0`, 기준 1.0배 선 `#FF0000` 점선 |
| 월별 손익 선 | 매출 `#FF6600`, EBITDA `#A6A6A6`, 영업이익 `#000000` |
| 현금·차입금 | 기말 현금 `#FF6600`, 차입금 `#595959`, 최소 보유현금 `#FF0000` 점선 |

차트를 새로 만들거나 고칠 때는 모든 계열에 색을 직접 지정한다. Excel 기본 테마색이 남으면 안 된다.

## 수식 규칙

- `OFFSET`, `INDIRECT`, 배열 수식, 외부 통합 문서 링크, 순환 참조를 쓰지 않는다. 추적과 검증이 어려워지기 때문이다
- 숫자를 수식 안에 직접 쓰지 않는다. 가정은 `전제사항`의 입력 셀에 두고 참조한다
- 한 행의 월별 수식은 왼쪽에서 오른쪽으로 같은 패턴이다. 실적 구간과 추정 구간의 구분은 `IF(월<=LastActual, 실적, 추정)`으로 한 수식 안에서 한다
- 실적 구간은 `실적_*` 시트를 링크한다. 실적 숫자를 본표에 값으로 붙이지 않는다

## 케이스와 매크로

- 케이스는 `Sensitivity`의 케이스 선택 칸 하나로 고른다. 스위치(시나리오 번호 등)는 이 시트에서 `전제사항`으로 링크된다. 스위치 셀에 직접 입력하지 않는다
- Case 1~3은 Base, Up, Down이다. Case 4 이후는 조건별 민감도, 마지막 Case는 자유 입력이다
- `민감도 갱신` 단추: 케이스를 차례로 계산해 결과를 저장값으로 기록한다. `민감도및결과`의 비교표는 이 저장값을 보여 준다. 가정을 바꾼 뒤 누른다
- `기준값 갱신` 단추: 검증이 비교 기준으로 삼는 값을 현재 계산값으로 덮어쓴다. 가정을 확정했을 때만 누른다. 누른 뒤의 "검증 OK"는 "기준값 갱신 이후 달라진 것이 없다"는 뜻이다

## 검증 항목

`민감도및결과`에 OK/NO로 모인다.

| 항목 | 뜻 |
|---|---|
| 실적 대사 | 실적 구간의 손익이 원천 자료와 일치 |
| 대차 일치 | 매월 자산 = 부채 + 자본 |
| 현금흐름 연결 | CF의 기말 현금 = BS의 현금 |
| 최소 현금 | 추정 구간 매월 현금 ≥ 최소 보유현금 |
| 한도 | 한도대출 잔액 ≤ 한도 |
| 상환 스케줄 | 모델의 원금 상환 = 약정 스케줄 |
| 오류 값 | 오류 셀 없음 |

## 확장 시트를 붙일 때

업종 고유 계산을 별도 시트로 붙일 때는 위 규칙을 그대로 따른다. 가정·상세 구역(연주황 탭)에 두고, 결과는 해당 매출·비용 라인의 "수동 조정" 행으로만 넣는다. 본표의 수식은 고치지 않는다. 붙인 시트는 `모델정보`의 시트 표에 등록해야 구조도에 나온다.
