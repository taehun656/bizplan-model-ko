# 법인별 사업계획 합산

같은 모회사가 전액 보유한 여러 회사의 사업계획을 한 화면에서 볼 때 쓴다. 각 법인의 원본 모델과 합산 파일을 함께 보관한다. 법인세, 차입 상환, 한도 사용, 현금 부족과 신규 조달은 원본에서 계산한다. 한 회사의 남는 현금으로 다른 회사의 부족액을 메우는 가정은 들어가지 않는다.

```console
python scripts/combine_models.py --models Output/A.xlsm Output/B.xlsm --name "사업계획 합산" --out Output/그룹_BP2027_합산.xlsm --log Work/combine_log.md
python scripts/verify_model.py Output/그룹_BP2027_합산.xlsm --sources Output/A.xlsm Output/B.xlsm --out Work/combine_verify.md
python scripts/make_model_map.py Output/그룹_BP2027_합산.xlsm --out Output/그룹_BP2027_합산_Map.html
```

세 회사 이상이면 `--models`와 `--sources` 뒤에 파일을 더 적는다. 회사 이름은 원본의 `META_Info.company`에서 읽는다. 단위, 실적 마감 월, 케이스 번호와 이름이 같아야 한다. 월 범위만 다르면 `--align intersect`로 모든 원본에 있는 달만 포함할 수 있다. 동일한 회사나 합산 파일을 원본으로 지정할 수 없다.

## 제거 명세

`--eliminations Work/eliminations.csv`를 붙인다. UTF-8 CSV를 사용한다. 금액은 **원본의 표시 단위**로 적는다. 백만원 모델의 12.5는 1,250만원이다. 양수는 차감하고 음수는 가산한다. 같은 월과 줄의 여러 건은 더한다. 모든 케이스에 공통으로 적용한다.

```csv
month,statement,line,amount,description
2027-01,IS,매출,12.5,내부 납품 매출
2027-01,IS,매출원가,12.5,대응 매입 원가
```

| 구분 | 입력 가능한 줄 | 반영 방식 |
|---|---|---|
| IS 또는 손익 | 매출, 매출원가, 판매관리비, 영업외수익, 영업외비용, 이자비용, 감가상각비 | 매출총이익, 영업이익, 세전이익, 순이익, EBITDA까지 해당 부호로 전파된다. 이자비용 제거는 영업외비용에도 반영된다. |
| BS 또는 재무상태 | 유동자산, 비유동자산, 유동부채, 비유동부채, 자본 | 자산·부채·자본 소계에 반영된다. 매월 차변과 대변의 제거 후 대차가 일치해야 한다. |
| BS 또는 재무상태 | 기말 현금, 유동차입금, 비유동차입금 | 현금은 CF 기말 현금과 BS 유동자산, 차입금은 재원조달 기말 차입금과 BS의 해당 부채에 반영된다. |

손익은 해당 월의 거래액, BS는 해당 월말에 제거할 잔액을 쓴다. 소계에 이미 반영된 금액을 중복 입력하지 않는다. 감가상각비 줄은 EBITDA 가산액이다. 비용 제거가 있는 경우 해당 매출원가·판매관리비 줄도 명세에 반영한다. 법인세는 개별 신고 세액의 합을 유지한다. 원본 중 BS가 없는 회사가 있으면 합산 BS를 생략한다. 이 경우에도 현금·차입금 명세는 해당 월 요약에 반영할 수 있다.

## 읽는 법과 갱신

- `Sensitivity`에서 케이스 번호를 고른다. 회사별 저장 시트에는 원본을 케이스별로 재계산한 월별 값, 파일명, 원본 생성 시각, 읽은 시각이 있다. IS·BS·CF·재원조달에서 행 왼쪽의 윤곽 기호로 회사별 금액을 펼친다.
- `민감도및결과`의 회사별 기여 표는 마지막 표시 연도 기준이다. 손익은 기간 합계, 현금과 차입금은 마지막 달 잔액이다. 월별 금액이 한 회사라도 없으면 해당 월 합계는 빈칸이다. 원리금이 없으면 DSCR도 빈칸이다. 합산 DSCR은 합산 영업현금흐름을 합산 원금상환과 이자 지급액으로 나눈다. 재원조달에서 회사별 행을 펼치면 각 원본의 DSCR을 볼 수 있다. 원본은 세후 영업현금에 이자를 더해 원리금과 비교한다.
- 원본 가정이나 제거 CSV가 바뀌면 같은 명령으로 다시 만든다. 직전 파일은 `.xlsm.prev`에 보관한다. 원본 파일은 숨은 Excel에서 읽기 전용으로 연다.
- `verify_model.py`는 모든 케이스를 전환해 월별 합계와 회사별 소계를 재검산한다. `--sources`를 주면 저장된 원천 값을 원본에서 다시 비교하고 합산 생성 이후 만들어진 원본을 ‘낡은 합산’으로 보고한다.

## 적용 범위

이 파일은 사업계획의 단순 합산표다. 정식 연결재무제표에서 요구하는 지분법, 비지배지분, 미실현이익 제거, 연결납세는 다루지 않는다. 회사 간 거래 식별과 제거 분개 작성은 사용자가 담당한다.
