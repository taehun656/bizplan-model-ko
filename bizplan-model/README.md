# 사업계획 재무모델 스킬

회사의 실적 자료를 AI에게 주면 내년 사업계획 재무모델을 만들어 주는 작업 절차서(스킬)입니다. 이 폴더를 AI 도구에 넣고 "사업계획 모델을 만들어 줘"라고 하면 됩니다.

## 무엇이 나오는가

| 산출물 | 내용 |
|---|---|
| 매크로 포함 Excel 모델(`.xlsm`) | 월별 손익·재무상태표·현금흐름, 차입 약정별 상환·연장과 이자, 현금 부족분 조달, 법인세(법인세법 세율표, 이월결손금, 최저한세, 이월세액공제, 농어촌특별세, 중간예납·확정 신고 납부 시기, 지방소득세), Base/Up/Down 시나리오, 민감도, 입력 검증과 자체 검증 |
| 모델 구조도(`.html`) | 어떤 가정이 어떤 계산을 거쳐 어떤 결과에 닿는지 보여 주는 화면. 브라우저로 엽니다 |
| 결과 요약(`.md`) | 결과 숫자, 주요 가정과 근거, 확인이 필요한 사항 |
| 합산 파일(`.xlsm`, 선택) | 법인별 모델이 둘 이상이면 합산 통합문서를 만들 수 있습니다 |

## 어떻게 진행되는가

1. AI가 필요한 자료 목록을 알려 줍니다.
2. 평소 쓰시는 파일을 그대로 `Input` 폴더에 넣습니다.
3. AI가 자료를 읽고 "매출은 이렇게, 비용은 이렇게 추정하겠다"고 설명합니다. 여기서 최소 현금, 한도대출 한도, 임금 인상률 같은 것을 정해 주시면 됩니다.
4. 모델, 구조도, 요약이 `Output` 폴더에 생깁니다.

꼭 필요한 자료는 최근 1~2년의 월별 손익계산서 또는 분개장 하나입니다. 재무상태표, 차입 명세, 매출 계획이 있으면 더 정확해집니다.

## 필요한 환경

- Windows PC, Microsoft Excel(데스크톱 설치본)
- Python 3.10 이상, 패키지 두 개: `pip install pywin32 openpyxl`
- 파일을 읽고 명령을 실행할 수 있는 AI 코딩 도구(Claude Code, Codex, Cursor 등)

## 설치

**Claude Code**: 이 `bizplan-model` 폴더를 `사용자 폴더\.claude\skills\` 아래에 복사합니다. 특정 프로젝트에서만 쓰려면 그 프로젝트의 `.claude\skills\` 아래에 둡니다.

**그 밖의 AI 도구**: 폴더를 아무 곳에나 두고 이렇게 말합니다.

> `C:\...\bizplan-model\SKILL.md`를 읽고 그 절차대로 우리 회사 사업계획 모델을 만들어 줘. 작업 폴더는 여기야.

## 사내에 배포할 때

- **회사 기준을 고정해 두기**: 작업 폴더에 `company_profile.md`를 두면 AI가 먼저 읽습니다. 계정 분류 기준, 보고 단위, 승인된 가정(임금 인상률, 최소 현금 등), 양식 선호를 적어 두면 담당자마다 결과가 달라지지 않습니다. 첫 실행이 끝나면 AI가 이 파일을 만들어 드릴지 묻습니다.
- **핵심 폴더는 고치지 않기**: `scripts`와 `assets`를 고치면 다음 버전을 받을 때 덮어써집니다. 회사 고유의 내용은 `company_profile.md`에 둡니다.
- **데이터 보안**: 이 스킬의 스크립트는 인터넷에 접속하지 않고 PC 안에서만 동작합니다. 다만 자료를 읽는 것은 사용하시는 AI입니다. 회사가 재무 자료 처리를 승인한 AI 도구에서만 쓰십시오.

## 모델 사용법

- **케이스 선택**: `Sensitivity` 시트의 케이스 선택 칸
- **가정 변경**: `전제사항` 시트의 노란 칸
- **`민감도 갱신` 단추**: 가정을 바꾼 뒤 누릅니다. 케이스별 결과를 다시 계산해 비교표에 반영합니다
- **`기준값 갱신` 단추**: 가정을 확정했을 때만 누릅니다. 검증의 비교 기준을 현재 값으로 바꿉니다
- 파일을 열 때 "매크로 사용" 확인이 뜨면 허용해야 단추가 동작합니다
- 노란 칸에 빈칸·음수·문자처럼 말이 안 되는 값을 넣으면 결과 화면의 "모델 검증 n/n OK" 숫자가 줄어듭니다. `검증` 시트에서 어느 칸인지 찾아 고친 뒤 결과를 쓰십시오

## 알아 두실 점

- AI가 만든 가정은 실적에서 계산한 출발점입니다. 결과 요약의 "확인이 필요한 사항"을 반드시 검토하십시오.
- 매출 계획의 현실성은 모델이 판단하지 않습니다. 회사가 준 계획이 실적 추세와 크게 다르면 표시만 합니다.
- 법인세는 대한민국 법인세법·지방세법 기준(2026년 11월 확인)으로 계산합니다. 세액공제·감면과 세무조정은 알려 주신 금액만 반영하므로 실제 신고 세액과 다를 수 있습니다. 세법이 바뀌면 `references/tax_rules_kr.md`의 세율표를 확인하십시오.
- 업종 고유의 제약(설비 가동률, 생산능력 등)은 기본 모델에 들어 있지 않습니다. AI가 필요하다고 판단하면 상의 후 추가합니다.
- 이 스킬은 계획 수립을 돕는 도구입니다. 결과에 대한 판단과 책임은 사용자에게 있습니다.
